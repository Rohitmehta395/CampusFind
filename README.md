# CampusFind

CampusFind is a smart campus lost & found platform with automatic lost/found item matching designed to reduce friction between losing an item and recovering it. Built specifically for college campuses, it enables students and staff to report lost and found belongings, discover potential matches with confidence scoring, submit and verify ownership claims, and communicate safely to resolve items efficiently.

## Status

Phase 0 of a phased build-out.

## Tech Stack

- **Frontend:** React + Vite + Tailwind
- **Backend:** Java Servlets + Apache Tomcat + Maven
- **Database:** MySQL + JDBC
- **Image Storage:** Cloudinary

## Project Structure

CampusFind is configured as a single monorepo hosting both applications side by side:

- `/frontend` — Holds the React app.
- `/backend` — Holds the Java web application.
